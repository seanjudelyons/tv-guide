# tv-guide

One combined XMLTV guide built from the free guides at [i.mjh.nz](https://www.matthuisman.nz/2017/07/australia-iptv-epg-files.html):
Australian free-to-air (Sydney), Pluto TV (US, CA, GB), Samsung TV Plus (US, GB, IN) and Plex (AU).

Rebuilt every 6 hours by GitHub Actions and published to the `guide` branch:

https://raw.githubusercontent.com/seanjudelyons/tv-guide/guide/guide.xml.gz

Made for players that accept only one guide source (for example the free version of TiviMate).
